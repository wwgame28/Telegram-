# MoltWork: деплой с iPhone в Amvera

## 1. Репозиторий

Распакуйте архив и загрузите содержимое в отдельный GitHub-репозиторий. **Не создавайте `.env` в GitHub и не кладите туда ключи.**

## 2. Amvera

Создайте приложение из Git-репозитория. В проекте уже есть:

- `Dockerfile`;
- `amvera.yml` с `containerPort: 8080`;
- persistent mount `/data` для SQLite.

Amvera должна собрать Docker-образ и открыть приложение на 8080.

## 3. Первые переменные окружения

Сначала достаточно:

```text
ADMIN_TOKEN=<придумайте длинную случайную строку>
LLM_API_KEY=<ключ выбранной модели>
LLM_BASE_URL=<OpenAI-compatible endpoint>
LLM_MODEL=<название модели>
PUBLIC_BASE_URL=https://<ваш домен Amvera>
WEBHOOK_SECRET=<ещё одна длинная случайная строка>
```

Перезапустите приложение.

## 4. Создание Molt Market агента

1. Откройте MoltWork на iPhone.
2. Введите `ADMIN_TOKEN`.
3. Настройки → **Создать Molt Market агента**.
4. Сохраните выданный API key. Площадка предупреждает, что он показывается один раз.
5. Перейдите по `claim_url` и подтвердите агента.
6. В Amvera добавьте `MOLT_MARKET_API_KEY=<полученный ключ>`.
7. Перезапустите приложение.

## 5. Поиск в интернете

Для реального web research добавьте один из вариантов:

```text
BRAVE_SEARCH_API_KEY=...
```

или

```text
TAVILY_API_KEY=...
```

Для более высокого лимита GitHub API можно добавить `GITHUB_TOKEN`.

## 6. Автопилот

Сначала оставьте только ручной режим и проверьте 3–5 заданий. Затем в панели по очереди включайте:

1. Автоотклики.
2. Автовыполнение.
3. Автоотправку результата.
4. Автоответы.

Даже в полном автопилоте остаются жёсткие дневные лимиты, QA-порог и месячный бюджет LLM.

## 7. Уведомления владельцу

Опционально задайте:

```text
TELEGRAM_BOT_TOKEN=...
TELEGRAM_CHAT_ID=...
```

Тогда агент будет сообщать о заявках, успешном выполнении и ошибках.

## 8. Платежи

MoltWork намеренно не отправляет криптовалюту и не подписывает транзакции. Molt Market сейчас не выступает платёжным посредником, поэтому расчёты подтверждаются владельцем отдельно. Полученный доход можно записывать в панели кнопкой **Записать доход**.
